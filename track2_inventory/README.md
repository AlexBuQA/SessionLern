# Трек 2. RL в собственной предметной области: управление запасами

Небольшая собственная Gymnasium-среда моделирует закупку одного товара при пуассоновском спросе, поставке на следующий день, потерянных продажах и ограниченном складе. Исследовательский вопрос: **сохранит ли Q-learning прибыль при незнакомом росте спроса, если во время обучения менять средний спрос от эпизода к эпизоду?**

## Запуск в VS Code

```powershell
cd track2_inventory
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
pytest -q
python run.py --config configs/smoke.json --output results/smoke
python run.py --config configs/full.json --output results/full
```

Полный запуск: 2 условия × 3 seed × 30 000 эпизодов по 30 дней. PyTorch не нужен. Каждый агент затем проходит 50 эпизодов при каждом λ = 3, 6, 9, 12, 15. Начальные остатки и потоки спроса согласованы по seed между стратегиями.

## Что реализовано

- `InventoryEnv` с корректными `reset/step`, `MultiDiscrete` и `Discrete`;
- Q-learning с ε-исследованием и отдельной оценкой без обучения;
- baseline `order-up-to S=15` и случайная стратегия;
- прибыль, уровень обслуживания, дефицит, хранение и заказы;
- кривые обучения, графики переноса, траектории на одном эпизоде и тепловая карта политики;
- автоматический отчёт `results/full/RESULTS.md` на основе реальных CSV.

Файл `training_returns.csv` содержит обучающие награды, но основная кривая строится по отдельным контрольным эпизодам при λ = 6, чтобы разные распределения спроса в обучении не искажали сравнение.

Smoke-конфигурация проверяет только сквозную работоспособность и не предназначена для выводов.
