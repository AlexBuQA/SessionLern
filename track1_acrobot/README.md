# Трек 1. Агент в классической среде: Acrobot-v1

Исследуется не подбор learning rate, а **перенос политики на незнакомый шум управления**. Базовый PPO обучается без шума; экспериментальный — со случайным `torque_noise_max ∈ [0, 0.3]` на каждом эпизоде. Оба затем проверяются на одних и тех же seed при шуме 0, 0.25, 0.5, 0.75, 1.0 и 1.5 Н·м.

## Запуск в VS Code

```powershell
cd track1_acrobot
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
# CPU-сборка PyTorch; для GPU используйте команду с сайта PyTorch.
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
pytest -q
python run.py --config configs/smoke.json --output results/smoke
python run.py --config configs/full.json --output results/full
```

Полный запуск последовательно обучает 6 агентов (2 условия × 3 seed) по 100 000 шагов. Пилотный запуск на этом CPU занял около 4 минут; это значительно меньше лимита 30 минут **на один запуск**, но время зависит от процессора. Результаты сохраняются после каждого агента.

## Артефакты

- `learning_curves.png` и `learning_curves.csv` — оценка на фиксированном шуме 0.2 каждые 10 000 шагов;
- `evaluation_episodes.csv` — каждый финальный эпизод без обучения;
- `evaluation_by_seed.csv`, `summary.csv` — средние и разброс между seed;
- `robustness_return.png`, `robustness_success.png` — устойчивость к знакомому и новому шуму;
- GIF — поведение итоговых агентов при новом шуме 0.5 Н·м;
- `RESULTS.md` — отчёт с фактическими числами после запуска;
- `config.json`, `runtime.json` — параметры и версии среды запуска.

## Метрика успеха

Acrobot выдаёт `-1` за каждый незавершённый шаг и `0` при достижении цели. Поэтому более высокая (менее отрицательная) награда означает более быстрый подъём. Неуспешный эпизод обрывается после 500 шагов. Финальная оценка использует детерминированный `model.predict`, без обновления весов.

PPO выбран после отдельного пилотного сравнения работоспособности: исходная DQN-конфигурация нестабильно решала среду при выбранном бюджете, тогда как PPO достиг 100% успеха на 20 эпизодах при шуме 0, 0.2 и 0.5. Алгоритм затем зафиксирован для обоих условий; это не часть контролируемого сравнения fixed/randomized.

Отчёт по проведённому запуску находится в [`results/full/RESULTS.md`](results/full/RESULTS.md). Smoke-результаты не используются для научных выводов.
